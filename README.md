## 💻 How to Run the Project

You can run PLAYVERSE locally on your computer by following these steps.

### Step 1: Clone the Repository

Open a terminal and run:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the actual URL of your GitHub repository.

### Step 2: Open the Project Folder

```bash
cd PLAYVERSE
```

### Step 3: Check the Project Files

Make sure the project files are available:

- `index.html`
- `style.css`
- `script.js`

Also ensure that the CSS and JavaScript files are correctly linked inside the HTML file.

### Step 4: Launch the Website

Open `index.html` in your web browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension if you prefer to preview the website through a local development server.

No build process is required for a basic HTML, CSS, and JavaScript project.
